## Implementación

`@supabase/supabase-js` 2.119.0 por npm/pnpm, versión consultada en el registro oficial. Solo URL y publishable key en frontend. `signUp` inserta id/nombre en perfiles; el inicio y la recarga leen ese registro bajo RLS. Si el registro se interrumpe, puede recuperar exclusivamente su propio perfil con su metadata autenticada. Las contraseñas se envían solo a Supabase Auth; no se almacenan en archivos, tabla perfiles ni logs. La sesión se conserva con el cliente estándar. El estado fiscal de demostración se limpia al cambiar usuario o cerrar sesión.

La cuenta y el nombre son persistentes y reales; tickets, facturas y declaraciones de esta versión continúan siendo demostración. El backend privado de Sites no se publica ni se conecta a esta nueva identidad.
